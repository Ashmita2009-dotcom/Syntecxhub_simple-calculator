# Calculator CLI

A beginner-friendly command-line calculator built in Python with a simple menu-driven interface.

## Features

- Addition, subtraction, multiplication, and division
- Clear screen option
- Input validation for invalid numbers and empty entries
- Division-by-zero protection
- Repeat calculations until the user exits
- Optional direct operator input support

## Requirements

- Python 3.8+

## Installation

1. Clone or download the project folder.
2. Navigate to the project directory.
3. Run the script with Python.

## How to Run

```bash
python calculator.py
```
